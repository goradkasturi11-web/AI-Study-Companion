# AI Study Companion

A basic Phase 1 website for an AI Study Companion project.

## Technologies
- HTML5
- CSS3
- JavaScript

## Pages
- Home
- Login
- Register
- Dashboard
- Subjects
- Smart Notes
- Quiz
- AI Assistant
- Study Planner
- Progress

## Phase 1
This version focuses on the user interface, page navigation and basic JavaScript demonstrations.

## Future Phases
- Real user authentication
- Database
- AI API integration
- Dynamic quiz generation
- AI note summarization
- Persistent study planner
- Real progress tracking

## How to Run
Open `index.html` in a web browser. No server is required for this basic Phase 1 version.
